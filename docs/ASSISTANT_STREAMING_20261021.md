# 知识助手流式与Word生成

流式通路：本地模型SSE → Python代理逐块转发 → Pi text_delta事件 → Python请求级缓冲 → 原生认证桥轮询 → 前端追加。完成后用最终结果校准内容。缓冲按管理员知识会话隔离，保留10分钟，轮询不进入模型任务锁。

文档请求：识别中文生成/整理/输出及doc、docx、Word。明确请求进入确定性工具编排：检索会议依据 → Pi Agent编写正文 → createDocument保存DOCX → 返回实际文件打开按钮。普通问答继续使用Pi工具循环。新主题独立处理，指代请求使用上轮主题和回答；资料不足时不生成虚构文档。文档正文仍需人工核对，检索相关性与小模型表达存在边界。

前端生产构建、Windows原生编译与18项后台测试通过。真实模型与主程序验收另附运行证据。

## 真实主程序验收

白鹤滩投产状态问答：Pi实际调用knowledgeSearch，174条流式事件，首段17秒，整段21.7秒。随后从当前回答生成doc：实际调用knowledgeSearch和createDocument，228条流式事件，首段9.92秒，16.19秒完成。生成《白鹤滩电站投产状态会议记录》DOCX共37205字节，实读正文含白鹤滩主题且未混入核电议题。以上为单次实际运行，不构成固定时延承诺。

18项Python测试和7个文档意图样例通过。
