# 事件主档改造验收

知识库以稳定事件ID为主标题。每次会议的事件详情、别称、发言人观点、结论、有效周期与原文ID作为来源记录归属事件。各会议结论分别保留。

入库先做中文向量与词项混合匹配，列出至多3个相似事件，默认新建，管理员确认归入已有事件或新建。相似度供审核参考，不作为正确率或自动合并依据。关联关系支持关联、前置依赖、后续行动、结论冲突、子事件，均绑定来源记录。

旧17条档案逐条迁移为事件主档，保留全部原记录，未自动猜测合并。迁移前后原记录逐字段一致，无孤立来源。未来可据关系表展示拓扑，本次页面展示关联标签和事件来源树。

14项单元测试通过，含跨会议归集、迁移幂等、最新版本检索、关联来源、自关联回滚、候选不自动归属、原文校验与既有文档功能。前端生产构建和Windows主程序编译通过。单元测试的向量/LLM使用替身；本次未宣称重新测试识别准确率。
